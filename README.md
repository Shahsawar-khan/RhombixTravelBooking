# 🌍 Rhombix Travel Booking System

Rhombix Travel Booking is a full-featured Laravel web application designed to simplify travel package exploration, real-time flight searches, and seamless booking management.

---

## 🔥 Key Features

### 👤 User Panel
- **Destination & Package Browsing:** Explore destinations and available travel packages.
- **Flight Search Integration:** Integrated with **Aviationstack API** to search live flights worldwide.
- **Dynamic Booking System:** Interactive multi-traveler booking flow with real-time price calculation.
- **Booking Confirmation & Receipt:** Instant booking reference generation and detailed confirmation view.

### 🛡️ Admin Panel
- **Dashboard Overview:** Monitor key statistics, total bookings, revenue, and destinations.
- **Package & Destination Management:** Create, edit, update, or remove packages and travel destinations.
- **Booking Management:** Review incoming guest/user bookings and manage approval statuses (`Pending`, `Confirmed`, `Rejected`).

---

## 🛠️ Tech Stack

- **Framework:** [Laravel 11](https://laravel.com/)
- **Frontend:** Blade Templates, Custom CSS, Tailwind CSS / Vite
- **Database:** MySQL
- **API Integration:** Aviationstack API (Flight Data)
- **Authentication:** Laravel Breeze / Custom Guards
